## Images

Every image on both demonstration sites is original vector artwork generated by
`src/server/demo/images.ts` from deterministic scene specifications (landscapes, storefronts
with the fictional business name on the sign, event posters, service icons) and rendered
to raster through the same upload pipeline as user uploads. No stock photography, no
hotlinked images, no third-party logos. Rights: created for this project, released under
CC0-1.0; each asset row records this license, an attribution note and its fixture key in
`source_url` (`fixture://<site>/<key>`).

## Favicon

`src/app/icon.svg` is an original two-letter mark drawn for this project.

## Fixture text

All place, event, article, store, service and page copy is written for the demonstration.
Names, addresses, phone numbers (555 exchange), `.example` domains and organizations are
fictional; none describes a real Colorado business, and no real Niwot organization is
referenced.
